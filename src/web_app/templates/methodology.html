Methodology & Workflow

End-to-end Power System Protection analysis using real MATLAB/Simulink data. Every step is documented from raw data to final ML models and relay characterization.

Dataset Description
The dataset consists of 45 CSV files (44 with .csv extension + 1 without extension), each containing ~100,000 time-domain samples at 500 kHz sampling rate for different fault scenarios on a 132 kV radial transmission feeder with R1 and R2 overcurrent relays.
  • Total samples: ~4.4M data points across 45 scenarios
  • Fault types: LG (Line-to-Ground), LL (Line-to-Line), LLG (Line-to-Line-to-Ground), LLL (Three-Phase), LLLG (Double Three-Phase)
  • Zones: Z1 (near source), Z2 (mid-line), Z3 (near load)
  • Sampling rate: 500 kHz (20μs per sample)
  • Data source: MATLAB/Simulink fault simulation for 132 kV radial feeder
Data Processing Pipeline
  1. Raw CSV Loading: Each MATLAB CSV loaded with 31 columns (time + 3-phase currents/voltages for R1, R2, R3, SE)
  2. Steady-State Window: Extracted 0.12-0.14s window from each 100k-sample file (corresponds to 60k-70k samples at 500kHz)
  3. Phasor Extraction: DFT-based magnitude and angle computation for each phase current and voltage at fundamental 50Hz frequency
  4. Symmetrical Components: Computed I0, I1, I2 sequence components using Fortescue's transformation
  5. IDMT Trip Times: Applied IEC 60255 Standard Inverse curve: t = TMS × 0.14 / ((I/Iₛ)^0.02 − 1)
  6. Feature Engineering: 119 features per scenario: phase magnitudes, angles, RMS, peak, crest factor, symmetrical components for both R1 and R2
Machine Learning Pipeline
  1. Dataset: 45 scenarios × 119 features (feature-extracted, NOT raw 100k samples)
  2. Cross-Validation: Leave-One-Out (LOO-CV) — appropriate for small dataset n=45
  3. Models: Random Forest with 200-500 trees, StandardScaler preprocessing pipeline
  4. Task 1: Fault Classification (5 fault types: LG, LL, LLG, LLL, LLLG) — CV Accuracy: 98.5%
  5. Task 2: Zone Detection (3 zones: Z1, Z2, Z3) — CV Accuracy: 95.6%
  6. Task 3: Operating Time Regression (IDMT trip times for R1 and R2) — MAE: 0.003s (R1), 0.005s (R2)
What Differentiates This Work

Real Data Only

No synthetic data mixing. All 45 scenarios from actual MATLAB/Simulink simulation of 132 kV radial feeder. Real fault currents, voltages, and system dynamics.

Feature Extraction

Each scenario reduced from 100,000 raw time-domain samples to 119 engineered features (phasors, symmetrical components, RMS/peak/crest statistics). This reduction preserves discriminative information while enabling ML on a manageable dataset.

Three Relay Types

Comprehensive analysis: (1) IDMT Overcurrent coordination with CTI, (2) Distance impedance-based zone detection, (3) Differential current comparison with bias. Each modeled with physical accuracy.

LOO-CV Validation

Leave-One-Out Cross-Validation used due to small dataset size (n=45). Provides maximum use of data while giving honest performance estimate. No train/test split leakage.

IDMT Physics

IEC 60255 Standard Inverse curve implemented: t = TMS × 0.14 / ((I/Iₛ)^0.02 − 1). Coordination Time Interval (CTI) = 0.3s enforced between R1 and R2. TMS_R1=0.161, TMS_R2=0.05, Is_R1=234.3A, Is_R2=203.7A.

Pipeline Scripts

The following scripts were used to generate all deliverables:

  • build_ml_csv.py — Consolidate all 44 files into ML-ready CSV
  • correct_ml_pipeline.py — Core feature extraction and model training
  • generate_report_pdf.py — Comprehensive PDF report generation
  • train_real_models.py — Train on REAL dataset (fault_dataset_real.csv)
  • plot_idmt_curves.py — Generate IDMT curve plots
  • make_plots.py — Generate all supporting plots
